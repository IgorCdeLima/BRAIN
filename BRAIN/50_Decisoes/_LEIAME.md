# 50_Decisoes — ADRs do ambiente

Decisões de arquitetura do **próprio ambiente 01_IA** (agentes, Brain, Git, Orca, permissões).

- Formato ADR: contexto → decisão → alternativas → consequências → status.
- Numeração sequencial: `ADR-0001 Título.md`.
- Decisões de um projeto ficam no repositório do projeto (`docs/adr`), não aqui.
- Uma decisão nunca é apagada: é marcada como `substituida` com link para a nova.
- Novas decisões só são aceitas com aprovação humana.
