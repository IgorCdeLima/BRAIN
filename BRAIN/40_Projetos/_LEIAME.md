# 40_Projetos — notas sobre projetos

Uma nota-hub por projeto, para pesquisa futura: visão geral, link para o repositório, aprendizados e conhecimento gerado.

- **A documentação oficial do projeto NÃO fica aqui.** Ela vive sempre na pasta/repositório do próprio projeto (`projetos/<nome>/docs`).
- Aqui ficam apenas referências e aprendizados úteis fora do projeto.
