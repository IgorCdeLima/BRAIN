# projetos

Cada subpasta é um projeto com **repositório Git próprio**, ignorado pelo repositório `01_IA`.

A documentação oficial de cada projeto vive dentro dele:

- `docs/requisitos/` — requisitos e critérios de aceite
- `docs/modelos/` — diagramas em Mermaid (UML, C4, ER)
- `docs/adr/` — decisões de arquitetura do projeto
- `qualidade/` — verificações, bugs e achados de segurança do projeto
