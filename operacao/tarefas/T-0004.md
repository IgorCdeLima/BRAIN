# T-0004 — Separar dependências de teste da imagem de execução

## Objetivo

A imagem que roda a aplicação não deve levar `tests/`, `pytest` nem o cliente HTTP de testes (observação A3 do piloto 1).

## Critérios de aceite

- [ ] Dependências de teste em arquivo separado (ex.: `requirements-dev.txt`).
- [ ] Imagem de execução sem `tests/` e sem dependências de teste; testes continuam rodando com um comando documentado no README.
- [ ] Verificavel com `docker compose run --rm app sh -c "ls /code; pip list"` (pasta `projetos/lab`, apos `docker compose build app`): a saida nao mostra `tests/`, `pytest` nem o cliente HTTP de testes.
- [ ] Sugestao: excluir `tests/` e os arquivos de dependencias de desenvolvimento pelo `.dockerignore` (ja existe) em vez de copiar arquivo a arquivo.
