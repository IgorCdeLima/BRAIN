## Objetivo

Levantar os requisitos e desenhar a arquitetura para rodar o ambiente 01_IA (Claude Code, git, hooks, `ferramentas/`, tmux) num container reproduzivel, no projeto `projetos/ambiente`. Resultado: requisitos, modelos Mermaid e ADR `proposta` em `projetos/ambiente/docs`, prontos para a analise de ameacas da Seguranca (proximo cartao) e para a escolha do humano sobre o Docker dos projetos.

  - [[Claude Code em container usa a Dev Container Feature, volume em CLAUDE_CONFIG_DIR e usuario nao root]]

  - [[Arquivos do volume montado ficam com o dono certo rodando o container com o UID do usuario do host]]
  - [[tmux em container exige TERM tmux ou screen, locale UTF-8 e window-size para varios clientes]]
  - [[Orquestrar sessoes do Claude Code - -p com permission-prompts none, hooks Stop e SessionEnd, mensagem entre sessoes e agent teams experimental]] (so para registrar o que fica para a fase 3)

- [ ] `docs/requisitos.md` (ou equivalente) com requisitos funcionais e nao funcionais numerados, cada um verificavel, cobrindo os itens abaixo.

- [ ] **Login do Claude Code** fora da imagem (`CLAUDE_CONFIG_DIR` em volume), sem segredo na imagem nem no repositorio.
- [ ] **Usuario sem privilegio** com o UID/GID do humano, e como isso e passado (build ou execucao), para os arquivos dos volumes ficarem com o dono certo.
