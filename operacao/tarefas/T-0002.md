# T-0002 — Cadastro e listagem de produtos (nome, valor, fornecedor)

## Objetivo

Permitir cadastrar produtos e vê-los listados na página inicial (RF-02 e RF-03).

## Contexto

- Depende de: T-0001 (concluída e mergeada).
- Validações em `docs/requisitos/requisitos.md`; modelo de dados em `docs/modelos/modelos.md`.
- Fornecedor é **texto livre** (decisão nos requisitos).
- Lição do piloto 1: os testes usavam o mesmo banco da aplicação.

## Critérios de aceite

- [ ] Formulário na página inicial com nome, valor e fornecedor.
- [ ] Validações conforme os requisitos, com mensagens de erro na própria página e os valores digitados preservados.
- [ ] Valor armazenado como `NUMERIC(10,2)` e tratado como `Decimal` (nunca `float`).
- [ ] Listagem do mais recente para o mais antigo, com valor formatado em reais (R$ 1.234,56).
- [ ] Testes isolados do banco da aplicação (banco de teste separado ou transação com rollback por teste).
- [ ] Testes para cadastro válido, cada regra de validação e ordem da listagem.
- [ ] `docs/modelos/modelos.md` coerente com a tabela criada.

## Restrições / o que NÃO fazer

- Sem imagem (T-0003). Sem edição nem exclusão de produtos.
- Não usar `docker compose down -v`.
- Não alterar `CLAUDE.md`, `.claude/`, `.githooks/` nem `qualidade/`. Se algo neles estiver errado, anotar em "Dúvidas em aberto".

## Verificações obrigatórias

- [ ] Testes automáticos passam
- [ ] Critérios de aceite atendidos
- [ ] Revisão de código (Revisor)
- [ ] Revisão de segurança leve: entrada do formulário escapada no HTML; SQL só via ORM/parâmetros
- [ ] Diagramas coerentes com o código
