# ADM-0026 - Trailers Agente/Tarefa/Modelo fora do bloco final de trailers

## Pedido

"pode investigar o trailer Agente num ADM" (humano, 2026-10-05, depois do push que levou o `bd0e4c2` do Pesquisador, em que `git log --format='%(trailers)'` nao mostrava `Agente`).

## Motivo

Hook do Git (`ferramentas/git/verificar_commit.py`) e area N4.

**Diagnostico (2026-10-05, so leitura):**

- O trailer **existe** no texto do `bd0e4c2`, mas num paragrafo antes do `Co-Authored-By`:

  ```
  docs(pesquisa): SEARCH-0009 ...

  Agente: pesquisador
  Tarefa: SEARCH-0009
  Modelo: claude-sonnet-5-5

  Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>
  ```

  O Git so le como trailer o **ultimo paragrafo**; `%(trailers:key=Agente)` volta vazio.
- **Causa:** o agente escreve os trailers na mensagem (o `CLAUDE.md` diz que todo commit termina com eles) e o Claude Code acrescenta o `Co-Authored-By` depois, em outro paragrafo. `commit_msg()` procura `Agente:`/`Tarefa:`/`Modelo:` em **qualquer linha**; achando os tres, nao mexe na mensagem. Quando o agente nao escreve, o hook acrescenta ao fim e fica certo.
- **Alcance:** BRAIN, 59 de 126 commits com `Agente:` no texto estao fora do bloco (coordenador 21, pesquisador 8, `claude-desktop` 30); lab, 22 de 92 (dev 7, revisor 7, designer 4, seguranca 2, administrador 2). Ex.: lab `873a336` (VER-T0013-01).
- **Efeito:** a consulta documentada em `Rastreabilidade` (`git log --format='%h %s%n%(trailers:key=Agente,key=Tarefa)'`) nao mostra esses commits. Nenhuma ferramenta do ambiente le os trailers pelo Git (`consumo.py` e `uso_brain.py` usam logs e transcricoes). O texto esta presente: `git log --grep='^Agente: dev'` acha todos.

## Mudanca proposta

- [x] 1. **Hook** (`commit_msg`): normalizar a mensagem. Retirar as linhas `Agente:`/`Tarefa:`/`Modelo:` de onde estiverem (mantendo a conferencia `Agente` = papel da sessao e os valores escritos pelo agente) e grava-las no bloco final de trailers: junto do ultimo paragrafo se ele ja for de trailers (ex.: `Co-Authored-By`), senao num paragrafo novo. Sem linhas em branco sobrando.
- [x] 2. **Teste** do hook em repositorio falso no scratchpad: mensagem sem trailers; com trailers no meio e `Co-Authored-By` no fim; com trailers ja no fim; com corpo; `Agente` diferente do papel (recusa).
- [x] 3. **`Rastreabilidade`:** trocar a consulta por uma que acha os dois formatos (`git log --grep='^Agente: <papel>'` e a de `%(trailers)` para os commits novos) e registrar que commits ate 2026-10-05 podem ter os trailers no corpo. **Historico nao e reescrito** (regra 6 do `CLAUDE.md`).
- [ ] 4. Commit no branch `admin/trailers`, merge `--no-ff` com o "sim" do humano.
