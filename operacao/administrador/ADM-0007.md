# ADM-0007 - Regra PowerShell de git add das pesquisas no perfil do Coordenador

## Pedido

"Pode corrigir o ponto 2."

## Motivo

O perfil `agentes/perfis/coordenador.json` tinha `Bash(git add operacao/pesquisas/*)` sem a variante `PowerShell(...)`. No Windows com PowerShell, esse `git add` pedia aprovacao, diferente do Bash.

## Mudanca proposta

- [x] Acrescentar `PowerShell(git add operacao/pesquisas/*)` ao `allow` do perfil do Coordenador.
