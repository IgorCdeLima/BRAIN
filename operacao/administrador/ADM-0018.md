# ADM-0018 - Script proprio para substituir as operacoes do Obsidian CLI

## Pedido

"Adicione um chamado para criarmos uma funcao para substituir as operacoes do Obsidian CLI."

"Ainda utilizarei o Obsidian como cofre. No entanto nao quero usar ele como ferramenta nessa aplicacao. Entao mantenha os padroes de escrita e de como e realizada a logica e links do Obsidian."

## Requisito: compatibilidade com o Obsidian

O `BRAIN/` continua sendo o cofre do Obsidian do humano; so a ferramenta sai do fluxo dos agentes. O script deve gravar exatamente como o Obsidian gravaria, para que backlinks, grafo e busca do aplicativo continuem certos:

- Resolucao de link como o Obsidian: `[[Nome]]` aponta para a nota com esse nome de arquivo em qualquer pasta; se o nome for ambiguo, usar o caminho completo a partir do cofre (`[[pasta/Nome]]`), como na opcao padrao "caminho mais curto quando possivel" (`newLinkFormat: shortest`). (Corrigido em 2026-10-02: antes dizia "menor caminho que distingue".) Respeitar `.obsidian/app.json` se o humano mudar essa opcao.
- Formas de link preservadas ao renomear: `[[Nome]]`, `[[Nome|alias]]`, `[[Nome#Cabecalho]]`, `[[Nome#^bloco]]`, `![[Nome]]` (embed), `[[Nome.md]]` e links Markdown `[texto](caminho%20com%20espaco.md)` (com codificacao de URL), mantendo alias, cabecalho e bloco.
- Frontmatter (propriedades) intacto: `aliases`, `tags` e demais campos nao sao reescritos; links dentro de propriedades (`"[[Nome]]"`) tambem sao atualizados.
- Anexos (imagem, PDF) seguem a mesma logica de nome e link.
- Nao tocar em `BRAIN/.obsidian/` nem em blocos de codigo (texto entre crases nao e link para o Obsidian).
- Nome de arquivo continua o titulo da nota (convencao atual), sem acentos em nota nova (regra 7).

## Motivo

O Bibliotecario so move e renomeia notas com `obsidian move`, que exige o aplicativo aberto (o lancador recusa o papel sem ele). Isso prende o ambiente a interface grafica e atrapalha a ida para Docker ([[ADM-0009]], em stand by). Alem disso, o CLI so atualiza links dentro do vault; links para notas do Brain em `operacao/`, `CLAUDE.md` e `agentes/` ficam de fora.

## Avaliacao do Administrador (2026-10-02)

- Uso hoje: `obsidian move` (mover e renomear), `obsidian orphans` e `obsidian unresolved` (manutencao). 4 commits com renomeacao no `BRAIN/` desde 2026-09-01.
- 154 notas; todos os links sao `[[Nome]]` simples (nenhum alias, cabecalho, embed, caminho ou link Markdown). Mover entre pastas nao muda link; so renomear exige reescrever as referencias.
- Nome repetido no vault: `_LEIAME.md` (varias pastas). O script deve recusar renomear para um nome que ja existe e avisar sobre nomes ambiguos.
- Complexidade estimada: baixa a media (script Python de 150 a 200 linhas + testes em pasta falsa + ajuste das regras).
